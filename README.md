## Datasets

The experiments in this work are conducted on the publicly available RSFAKE-1M and UW datasets.

### RSFAKE-1M Dataset

Download link:
https://huggingface.co/datasets/TZHSW/RSFAKE?utm_source=chatgpt.com

### UW Dataset

Download link:
https://figshare.com/s/eeedcd150e759ef4353c?utm_source=chatgpt.com&file=28889103

Please download the datasets from their official repositories and organize them according to the following structure:

datasets/
├── RSFAKE-1M/
├── UW/

Note:
We do not redistribute the datasets. Please comply with the licenses and usage policies provided by the original dataset authors.
